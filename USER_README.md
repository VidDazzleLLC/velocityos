# VelocityOS - User Guide

Welcome to VelocityOS, your autonomous AI business agent!

## Installation

1. Download the `VelocityOS_v1.0.zip` file.
2. Extract the contents.
3. Run the installer (`.exe` on Windows, or standard application package on macOS).
   - *Zero-touch installation*: It will automatically install to your user directory and create a desktop shortcut.
   - It will automatically launch after installation.

## License Activation

VelocityOS uses a strict one-computer license policy to ensure security and prevent unauthorized resale or sharing.

1. On first run, you will be prompted for your license file (`license.lic`).
2. Provide the signed JWT file provided to you upon purchase.
3. The system will securely tie the license to your machine's unique fingerprint (CPU, MAC address, Motherboard).
4. **Note:** If you attempt to copy the software or license file to another computer, core features will automatically disable.

## Features

- **Dashboard**: View real-time status, analytics, and control the autonomous agent.
- **Self-Healing**: If any internal process crashes, VelocityOS will automatically attempt to recover.
- **LLM Agnostic**: Bring your own API keys (OpenAI, Anthropic) or use local open-source models (Ollama). The system routes tasks dynamically for cost and speed.
- **Self-Improving**: VelocityOS continuously optimizes its own internal parameters to increase performance and reduce errors over time.
